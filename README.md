# Fee Management System on Microsoft Azure

A cloud-based Fee Management System developed using Microsoft Azure services.

## Features

- Azure Functions REST APIs
- Azure SQL Database
- Azure API Management
- Microsoft Entra ID Authentication
- Role-Based Access Control (RBAC)
- Azure Logic Apps
- Application Insights Monitoring
- Automated Fee Reminder Emails

## Technologies

- Python
- Azure Functions
- Azure SQL Database
- Azure API Management
- Microsoft Entra ID
- Azure Logic Apps
- Application Insights
